# TTV v0.4 — Scenes / Maps

## Цель

Сделать online-стол полноценным пространством игры: ДМ загружает свою карту, готовит несколько сцен, настраивает сетку и туман, размещает фишки, а игроки видят изменения без ручной перезагрузки.

## Что входит в v0.4

### Сцены

- несколько сцен в одной кампании;
- общая активная сцена;
- создание, переименование, переключение и удаление;
- переключение ДМом обновляет Player View.

### Карты

- приватное хранилище `campaign-maps`;
- PNG / JPEG / WebP;
- лимит 6 МБ на файл;
- путь файла привязан к campaign + scene;
- сервер создаёт временную ссылку только для доступной пользователю сцены;
- замена и удаление карты не ломают живую сцену даже при ошибке очистки старого файла.

### Вид карты

- zoom от 50% до 300%;
- pan средней кнопкой мыши;
- pan через `Space + drag`;
- камера локальна для каждого участника и не синхронизируется между пользователями.

### Сетка

- включение/выключение на сцене;
- размер клетки 16–256 px;
- X/Y offset;
- опциональный snap токена при отпускании.

### Фишки

Из панели сцены ДМ может:

- добавить уже существующего Actor на сцену;
- скрыть/показать фишку;
- менять её размер;
- убрать фишку со сцены, не удаляя самого Actor.

Live movement из v0.3 сохранён. Финальная позиция по-прежнему отдельно сохраняется как постоянное состояние.

### Fog of War

MVP v0.4 использует простые прямоугольные reveal-регионы:

- ДМ включает туман;
- включает режим открытия;
- протягивает прямоугольник по карте;
- игрок получает открытый участок после сохранения;
- ДМ может закрыть всю карту обратно.

Это намеренно не dynamic lighting. Стены, лучи зрения, двери и источники света остаются за пределами v0.4.

## Безопасность тумана

Fog of War не является только визуальным чёрным слоем.

Для обычного игрока чужой Actor/Token за закрытым туманом не проходит player-read правила. Свой назначенный герой остаётся доступен пользователю, но клиент не позволяет утащить его в закрытую область.

Live Broadcast токена также отключается, если NPC скрыт вручную или находится в закрытой fog-области. Это не даёт координатам скрытого NPC утечь через transient realtime movement.

## Зависимости и воспроизводимая сборка

v0.4 перестаёт использовать `latest` в package.json.

Добавлен `package-lock.json`, CI использует:

```bash
npm ci
npm audit --omit=dev --audit-level=high
npm run typecheck
npm run build
```

Транзитивные версии PostCSS/Sharp зафиксированы через overrides на исправленных версиях. Release CI должен показывать 0 production vulnerabilities.

## Ручной acceptance test

Нужны два браузерных сеанса и два аккаунта: ДМ и игрок.

1. Открыть одну online-кампанию в GM View и Player View; Presence показывает двух участников.
2. ДМ создаёт вторую сцену и переключает её; Player View автоматически переходит на неё.
3. В `▣ Сцена` загрузить небольшую PNG/JPG/WebP карту; после обновления состояния карта появляется у обоих.
4. Проверить zoom колёсиком и кнопками; проверить pan средней кнопкой и `Space + drag`.
5. Включить сетку, поменять размер/offset, включить snap; фишка после отпускания становится на сетку.
6. Добавить существующего NPC на сцену, поменять размер, скрыть/показать и убрать со сцены.
7. Проверить live движение видимого NPC — второй браузер видит сам drag.
8. Включить Fog of War. Player View должен стать закрытым.
9. Нарисовать прямоугольную открытую область; игрок должен получить её без F5.
10. NPC за закрытым fog не должен быть виден/читаться игроком и его движение не должно появляться live.
11. Передвинуть NPC в открытую область и отпустить — после сохранения он появляется игроку.
12. Игрок пробует перетащить своего героя в закрытый fog — позиция должна откатиться с понятным сообщением.
13. Запустить бой, когда часть NPC скрыта fog: Player View не должен ошибочно назвать другого видимого героя текущим ходом; если текущий Actor скрыт, показывается `Ход мастера`.
14. Обновить обе страницы и убедиться, что карта, настройки сцены, fog и позиции сохранились.

## Не входит

- dynamic lighting;
- line of sight;
- стены и двери;
- погодные эффекты;
- animated maps;
- тайловый редактор;
- события/триггеры карты — v0.4 лишь готовит под них сцену.

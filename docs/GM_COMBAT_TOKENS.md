# GM combat unlock + token multi-select

Ветка `test/gm-combat-and-tokens`.

## Что изменилось

### 1. Бой больше не блокирует инструменты мастера
- `combat_active` — оверлей, а не замена режима стола
- В бою доступны: Персонажи, Сцена (в режиме Подготовка), Инструменты, Кубы
- Меню режима: Игра / Подготовка остаются доступны во время боя

### 2. Multi-select фишек (только GM)
- Клик — одна фишка
- Shift / Ctrl / Cmd + клик — добавить/убрать из набора
- Клик по пустой карте — снять выделение
- Панель снизу: Скрыть · Показать · Убрать · Все NPC · ×

## Как проверить
1. Начать бой → в нижнем bar есть «Персонажи» и «Бой»
2. Меню стола → Подготовка / Сцена доступны во время боя
3. Shift+клик по 3 NPC → панель «Выбрано: 3» → Скрыть
4. Показать / Убрать / Все NPC

# TTV — tabletop campaign platform

TTV — универсальный VTT/GM-инструмент для кампаний с разными игровыми системами и сеттингами: от средневекового фэнтези и grimdark до sci-fi.

Главный продуктовый принцип: **ДМ не должен изучать сложный VTT, чтобы начать играть.**

```text
регистрация → кампания → приглашение → персонаж → сцена → игра
```

## Статус

**v0.4 — Scenes / Maps.**

Online-кампания уже объединяет аккаунты, роли, Player View, полный базовый GM-интерфейс, realtime и полноценные сцены с пользовательскими картами.

```bash
npm run typecheck

```

## Что уже работает

### Кампании и аккаунты

- регистрация и вход;
- online Campaign Hub;
- создание и удаление кампаний;
- Owner / GM / Assistant GM / Player / Spectator;
- многоразовая invite-ссылка на кампанию;
- регенерация и отключение ссылки;
- список участников;
- смена ролей и исключение игроков;
- назначение одного героя конкретному игроку.

### Игровой стол

- отдельный GM View и Player View;
- несколько сцен и общая активная сцена;
- персонажи и NPC;
- токены и сохранение их позиции;
- HP;
- инвентари;
- скрытые NPC и player-safe reads;
- общий combat runtime;
- полный online GM sidebar: Группа / Бой / Инвентарь / NPC / Заметки;
- online Мастерская: Предметы / NPC / Лут / Таблицы;
- создание/редактирование предметов и NPC;
- выдача предметов и drag & drop инвентаря;
- GM notes и roll tables.

### Realtime multiplayer

- приватный realtime-канал на кампанию;
- Presence: видно участников онлайн;
- live movement токена во время перетаскивания;
- финальная позиция сохраняется после отпускания;
- HP, сцена, инвентарь, бой и GM-изменения обновляются без ручного F5;
- скрытые токены не рассылают live-координаты игрокам.

### Scenes / Maps

- приватная загрузка карт PNG/JPG/WebP до 6 МБ;
- карта хранится внутри кампании и выдаётся через временную ссылку только тому, кто имеет доступ к сцене;
- создание, переключение, переименование и удаление сцен;
- zoom 50–300%;
- pan средней кнопкой мыши или `Space + drag`;
- настраиваемая сетка: размер клетки и X/Y смещение;
- snap токенов к сетке;
- добавление существующего персонажа/NPC на сцену;
- скрытие/показ фишек, изменение размера, удаление со сцены;
- Fog of War с прямоугольными открытыми областями;
- закрытие всей карты обратно;
- fog влияет не только на картинку, но и на доступ игрока к чужим NPC/токенам в закрытой области.

## Запуск

После первого clone или изменения зависимостей:

```bash
npm ci
npm run dev
```

Открыть:

```text
http://localhost:3000
```

Online campaigns:

```text
http://localhost:3000/campaigns/online
```

Production-проверка:

```bash
npm run typecheck
npm run build
npm run start
```

Для online-mode нужны публичные значения проекта в `.env.local`. Шаблон находится в `.env.example`.

## Архитектурный принцип

```text
Platform Core
  + Game System
  + Setting Pack
  + Theme
  = Campaign
```

Core не должен содержать D&D/Warhammer-специфичные сущности. Базовый домен универсальный:

```text
Actor
Item
Inventory
Scene
Token
Combat
Journal
Book
Permission
```

`Actor` используется для персонажа игрока, NPC, существа, транспорта, спутника и призыва. Специфичные игровые характеристики хранятся в `system_data`.

Предметы разделены на:

- `ItemDefinition` — шаблон предмета кампании;
- `ItemInstance` — конкретный экземпляр в инвентаре.

Realtime разделяет временное и постоянное состояние:

```text
быстрое движение → Broadcast
финальная позиция / HP / сцена / инвентарь / бой → постоянное состояние кампании
```

Скрытая информация не передаётся игроку полной записью через realtime. После изменения клиент перечитывает только разрешённые ему данные.

Подробно об архитектуре: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Продуктовая цель

TTV не должен выигрывать количеством настроек.

Он должен выигрывать временем от регистрации до первой совместной игры.

> Цель: ДМ и игроки оказываются на общей карте за несколько минут, а сложные возможности открываются только тогда, когда они реально нужны.

## Контент

Проект использует вымышленные generic-данные и не должен включать официальный защищённый контент коммерческих настольных систем без соответствующей лицензии.
